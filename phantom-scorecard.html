What Makes It Special

InnovationWhy It Matters
Adaptive Cognitive RouterMatches cognitive overhead to task complexity. A typo fix doesn't need a 5-agent plan. A cross-cutting refactor does. No other system adapts this way.
Artifact Pipeline"Files are truth, context is ephemeral." Solved the fundamental problem of context window systems: they designed for surviving long conversations instead of making short ones work. Each phase reads/writes JSON — no state lives in the prompt.
Auto-Triggering HoundMost forensic tools require manual invocation. This system detects bug-shaped inputs at start, verification failures at verify, and fix loops at fix — then auto-spawns investigation. Proactive, not reactive.
Power LevelReplaces the common "7-step verification" anti-pattern with a severity-based triage. P0/P1 get auto-fixed and block shipping. P2/P3 get dropped silently. Eliminates bikeshedding in review.
Anti-Repetition EnforcementEvery agent prompt includes past corrections from learnings. A mistake corrected once is structurally prevented from recurring. Most systems rely on prompt instructions — this system injects evidence.
