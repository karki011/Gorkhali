AXI Ecosystem

Deep research: axi.md + kunchenguid repos → integration opportunities for Phantom · researched 2026-07-02 · Subash Karki
TL;DR — AXI ("Agent eXperience Interface") is a design standard, not a framework: 10 principles for agent-native CLI tools that treat token budget as a first-class constraint. The CLIs (gh-axi, chrome-devtools-axi, lavish-axi, tasks-axi) are MIT reference implementations, actively maintained, zero-install via npx. Best Phantom fits: adopt the output contract for phantom's own tooling, wire lavish-axi into HTML artifact review, and fold chrome-devtools-axi into Lens.

Who / what

Kun Chen (kunchenguid) — Bellevue WA, ex-L8 Meta/Microsoft/Atlassian. 64 public repos, daily activity (July 2026 pushes). AXI's thesis: agents talk to the world through two lossy paradigms — human-built CLIs and MCP tool protocols — both wasting tokens. AXI is a third: agent-native CLIs where every byte of output earns its place. Benchmarks in the core repo: gh-axi 100% task success @ $0.050/task vs GitHub MCP 87% @ $0.148.

The 10 AXI principles

  1. Token-efficient output — TOON format (~40% savings vs JSON), converted only at the output boundary.
  2. Minimal default schemas — 3–4 fields per list item; --fields to opt into more.
  3. Content truncation — truncate with a size hint (… (truncated, 8432 chars total)) + --full escape hatch.
  4. Pre-computed aggregates — count: 30 of 847 total, checks: 3/3 passed inline to kill follow-up calls.
  5. Definitive empty states — say 0 closed tasks found explicitly.
  6. Structured errors & exit codes — idempotent mutations, errors on stdout, fail loud on unknown flags, exit 0/1/2, progress to stderr.
  7. Ambient context via session hooks — setup hooks installs a SessionStart hook injecting a compact dashboard; ship an Agent Skill as the lighter path.
  8. Content first — no-args invocation shows live data, not help text.
  9. Contextual disclosure — every response ends with help[N]: next-step suggestions.
  10. Consistent help — concise per-subcommand --help.

Reusable artifact: .agents/skills/axi/SKILL.md (installed via npx skills add kunchenguid/axi, the vercel-labs/skills format). CLI home view and SKILL.md are generated from one source with a CI --check drift gate.

Repo-by-repo

axi (core) — the spec + benchmarks

★ 1,246MITTSpushed 2026-07-01

Manifesto + two benchmark harnesses (bench-browser/, bench-github/) proving the principles beat raw CLI and MCP on cost / latency / turns / success.

gh-axi — GitHub CLI for agents

★ 131MITTSpushed 2026-07-02

Wraps official gh. Notable: run view --log-failed shows last 20k chars and saves the full log to a temp file surfaced as full_log + grep hint; secrets only via stdin; setup hooks surfaces open issues/PRs each session. 100% vs 86% success against raw gh; 66% cheaper than GitHub MCP.

chrome-devtools-axi — browser automation

★ 209MITTSpushed 2026-07-01

CLI → persistent bridge server on localhost:9224 → chrome-devtools-mcp → headless Chrome. Snapshot refs carry a generation prefix (uid=g<N>:) so stale refs fail loud (STALE_REF) instead of silently no-oping. Skill mandates verifying state changes with a fresh snapshot before claiming success. Best of 7 benchmarked browser conditions: 100% / $0.074 / 4.5 turns — 57% fewer tokens than raw chrome-devtools-mcp.

lavish-axi — human review for agent HTML

★ 1,388MITJSpushed 2026-07-02

"HTML is the new markdown." lavish-axi <file.html> opens the artifact locally with an injected annotation SDK; lavish-axi poll long-polls for human feedback or layout warnings. Sessions keyed by file path (no opaque IDs). Open-time layout gate masks the artifact until an in-iframe audit passes (overflow / clipped / overlapping text → layout_warnings with selector/kind/severity). Infers the subject project's design system (Tailwind/tokens) before falling back to its own. export inlines assets; share publishes (opt-in, third-party). State in ~/.lavish-axi/, loopback-bound.

tasks-axi — agent-ergonomic backlog

★ 15MITTSpushed 2026-06-29

Mutates a hand-editable backlog.md in place with byte-exact round-trip (render(parse(src)) === src). Dependency graph + ready query borrowed from beads. Advisory lockfile + atomic writes, idempotent mutations (already: true), --json confirmations. Pluggable Store backend (sqlite/github/jira planned).
