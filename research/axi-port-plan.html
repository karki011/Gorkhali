AXI → Phantom Port Plan

Absorb, don't call — unified plan from three source-level studies (axi/gh-axi/tasks-axi · lavish-axi · chrome-devtools-axi) · 2026-07-02 · Subash Karki · companion to axi-ecosystem.html
Strategy — Phantom stays self-contained: no axi CLI is called at runtime, no new npm dependencies. We port one script (the lavish layout audit, ~430 LOC, zero deps), six small stdlib helpers into scripts/lib/, and prose discipline into reference/agent files. Skill output style is modeled on lavish's SKILL.md (Subash's explicit preference) + the AXI 10 principles. Everything heavy — annotation server, export inliner, TOON dependency, bridge machinery, generation-ref mechanism — is deliberately skipped. One sanctioned exception: the optional annotation review surface (2.4) wraps lavish-axi via npx; core phantom works without it.

Wave 1 — Anchors (prose only, ~half day)

PROSE1.1 reference/output-contract.md (new)

Phantom-flavored AXI 10 principles, retargeted from "a CLI you build" to "output your scripts print / summaries your skills render." Keep axi's failure-mode-naming style ("An agent that reads 'Fetching data…' will try to interpret it as data"). Fold in lavish's loop discipline: fix fresh error-severity findings, proceed-with-a-note on persistent/low-severity ones; long-poll etiquette; and lavish's design-inference priority order (user's ask → subject project tokens → fallback) for artifact authoring. Record the stdin-only-secrets rule here (no code until a surface exists). Add one Core Discipline line to commands/_shared.md.

PROSE1.2 Lens discipline — agents/reference/visual-protocol.md + agents/lens.md

From chrome-devtools-axi (~20 lines total):

  • Verify before success — new step 6.5: re-snapshot + re-screenshot after every state-changing action before recording any result; no PASS without a post-action capture (a valid-ref click can silently no-op).
  • Ref hygiene — a ref is only valid against the snapshot that produced it; never carry @eN across a page-changing action (agent-browser re-numbers refs silently → wrong-element hazard).
  • Switch examples to snapshot -i; output-hygiene note (grep/head large output, artifacts to files not reports).
  • agents/lens.md Rules: 3 lines incl. STALE_REF/REF_NOT_FOUND as failure vocabulary in fix packets.

Wave 2 — Correctness + token wins (code, ~1–2 days)

HIGH2.1 scripts/lib/atomic.js — lockfile + atomic write (from tasks-axi lock.ts)

openSync(lock, "wx") advisory lock with retry-to-deadline + stale hint, token-checked release, sorted multi-path acquisition (deadlock avoidance), tmp-file + renameSync atomic writes, re-read-vs-snapshot conflict check. Wrap phantom's race targets today: memory-writer.js (fires every Stop), session JSON writers, learnings/INDEX.md, brain/evolution writes. Concurrent background agents make this a live correctness bug, not a nicety.

HIGH2.2 scripts/lib/log-capture.js — tail-truncate + temp file + grep hint (from gh-axi run.ts)

Keep the log TAIL (errors live at the end), save full log to a 0o600 temp file, emit help[1]: full log saved to {path} — grep it for earlier context. Adopt in verify/fix, phantom's biggest context flooders.

HIGH2.3 scripts/layout-audit.js — the lavish crown jewel (~430 LOC, zero deps)

Lift the audit engine + pure classifiers from lavish-axi/src/artifact-sdk.js:106-748 verbatim (drop postMessage/timer plumbing, keep font/ResizeObserver/rAF settle helpers). Expose window.__lavishAudit() → {selector, kind, overflowPx, severity}[]. Two consumers:

  • Lens (primary): after rendering any HTML artifact, evaluate the audit in-page and self-correct error-severity findings before the human sees it — lavish's poll→fix loop inside phantom's existing visual protocol.
  • Human-facing: inline into hound/visualflow/spec HTML templates as an in-page warning panel (artifacts open as file://, so render findings in-page).

Port the classifier unit tests too — they carry the false-positive edge-case knowledge (wrapped-text fragments, intentional scrollers, ellipsis truncation).

HIGH2.4 /phantom:annotate — lavish-axi annotation loop (wrap, not port · approved 2026-07-02)

New commands/annotate.md: open an HTML artifact with npx -y lavish-axi <file>, run lavish-axi poll <file> in the background, apply returned annotations (element selectors + text ranges + comments), re-open per --reopen etiquette, end when the human is done. Poll discipline from lavish SKILL.md: leave the poll running — queued feedback is never lost; fix fresh error-severity findings, proceed-with-a-note on persistent/low-severity ones.

  • Auto-invoked in the workflow (primary mode): whenever brainstorm / plan / visualflow produces an HTML artifact, the flow opens it through annotate automatically and starts polling — the human never has to ask for the file. Plan approval becomes annotate-in-browser; chat approval remains available.
  • User-invocable on any artifact path as well.
  • Fallback: if npx/network is unavailable, degrade to plain open <file> (today's behavior) — core phantom never depends on it.

Touches: new commands/annotate.md; auto-invoke wiring in commands/brainstorm.md, reference/brainstorm.md, reference/visualflow/, and the plan-approval step of commands/start.md.

Wave 3 — Output plumbing (code, ~1–2 days)

MED-HIGH3.1 scripts/lib/render-output.js

Boundary discipline without the TOON dependency: scripts build one plain object, render once at the end (never console.log mid-computation). Includes formatCount() (count: N of M total — 4 phrasings from gh-axi format.ts), renderHelp() (help[N]: hints), and the already: true idempotent no-op convention.

MED-HIGH3.2 scripts/lib/axi-error.js + HIGH3.3 SSoT schema docs

3.2 — PhantomError(message, code, suggestions[]) + exitCodeForError() (VALIDATION_ERROR→2, else→1); set process.exitCode, never process.exit. Route validate-artifact.js, check-learnings-index.js, preflight.js through it.
3.3 — make validate-artifact.js the single source of truth: export schema defs as data, new scripts/gen-schema-docs.js renders reference/schemas/*.md, --check mode fails CI on drift (gh-axi builds this but forgot to wire it into CI — we wire it).

HIGH3.4 scripts/lib/md-grammar.js — byte-exact markdown round-trip (from tasks-axi markdown-grammar.ts)

Raw-line retention: parse keeps original source lines, render regenerates only dirty entries. Round-trip test render(parse(src)) === src (incl. CRLF/empty/no-trailing-newline). Adopt for learnings/INDEX.md, learnings/{domain}.md, EDGES.md, brain cards — machine-appended AND human-edited files where edits currently risk reflowing untouched content.

Wave 4 — Adoption (ongoing)

MEDscripts/lib/fields.js (minimal default schema + --fields/--full, unknown-field → VALIDATION_ERROR listing valid names) → adopt in commands/status.md board output and session-health.sh. Then rewrite the highest-traffic skill outputs (status, verify, cost) in the lavish SKILL.md voice per reference/output-contract.md. Pair with the bloat-audit removals (separate track, report pending).
