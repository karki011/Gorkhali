Crew Agents

Cortex
opus
Team lead. Plans, decomposes, coordinates, self-challenges. Never implements directly.
Spark
sonnet
Implementation engine. Spawned with ROLE FOCUS directives (React, Go, tests, etc.). Max 5 concurrent.
Sentinel
sonnet
QA and build verification. Tests, lint, typecheck, build. Witness regression markers.
Hawkeye
opus
Cross-file reviewer. Cache coherence, regressions, dead code, convention deviations.
Prism
opus
Quality gate. KISS/DRY enforcement, simplifier gauntlet, architecture review.
Oracle
opus
Advisory only, no tools. On-demand guidance for Spark agents. Max 3 consultations per session.
Lens
sonnet
Visual verification. Browser-based UI inspection with structured fix packets.
Detective
opus
Forensic investigator. Traces symptoms to root causes via git history, hotspot analysis, coupling detection.

Detective Mode — Auto-Triggers

  • A
    Bug Report Detection — start.md Phase A.5
    Keywords: bug, broken, regression, error, crash, failing. Jira type: Bug. Branch: fix/*, hotfix/*
    Depth: Pre-scan (2-3 git commands, adds detective field to context.json)
  • V
    Verification Failure — verify.md Step 1 failure
    When lint, build, or tests fail, scan failing files before routing to fix
    Depth: Failure scan (4-5 git commands, adds detective field to verification.json)
  • F
    Fix Loop 2+ — fix.md Step 8.5
    Same failure class repeats after first fix attempt. Full forensic investigation before scrap-and-redo
    Depth: Deep investigation (full 7-step protocol, produces investigation.html)

Iron Laws

#1 Feature branch — never commit on main/develop/master
#2 Verification mandatory — Sentinel confirms pass
#3 Anti-repetition — scan learnings before any approach
#4 Devil's Advocate — every plan challenged
#5 Simplify always runs — after verify pass
#6 Intent check — diff vs contract intent
#7 Smart PR — UI = branch only, no UI = draft PR
#8 Jira auto-transition — after push/PR
#9 Learnings — every session reads and writes
#10 Auto-CREW — 4+ files, cross-cutting = CREW
#11 Root cause or nothing — reproduce, trace, confirm, fix
#12 Parallel agents — 2+ independent files = parallel
#13 Subagent-driven — all implementation through Agent tool
